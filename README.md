## boneun-mal-shorts

보이는 말 · BONEUN MAL — a Korean Sign Language / Deaf culture YouTube Shorts
pipeline (KCISA 한국수어 OpenAPI → verified human KSL clip → 9:16 FFmpeg render →

run stops rather than fake one. See [`boneun-mal-shorts/README.md`](boneun-mal-shorts/README.md).
